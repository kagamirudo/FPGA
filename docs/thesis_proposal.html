Compiler-Emitted Nearest-Neighbor Systolic Arrays on FPGA

A Kung-style LU and Brent–Luk–Van Loan Jacobi SVD case study, benchmarked against Vitis HLS
MS Thesis Proposal · Gary Pham · Drexel ECE
Advisor: Prof. Prawat Nagvajara · Draft prepared 2026-09-30 for winter term (Jan 27) start

1. Motivation

FPGA systolic arrays remain one of the most efficient substrates for dense linear algebra, but designers still hand-write RTL for each kernel or accept the area/latency overhead of high-level synthesis. Polyhedral-to-systolic compilers such as AutoSA (FPGA’21) have shown that schedules can be generated automatically, yet the emitted arrays typically use long-range interconnect and non-streaming interfaces, which complicates system integration on modern AMD/Xilinx platforms where AXI4-Stream is the lingua franca.

This thesis argues for the opposite constraint set: strict nearest-neighbor connectivity and AXI4-Stream–compliant outputs by construction. The claim is that this constraint pair, once baked into a shared PE template, is expressive enough to cover several important dense-linear-algebra kernels while yielding place-and-route results competitive with, or better than, Vitis HLS on the same C source.

2. Prior Work Positioning

FPGA implementations of SVD are dense in the literature. The Brent–Luk–Van Loan mesh [1] underlies most subsequent designs, including Hemkumar & Cavallaro's complex-matrix CORDIC array [2], Ma et al.'s FPGA SVD processor [3], Ahmedsaid & Amira's improved systolic array [4], the Iowa State Hestenes–Jacobi work by Wang & Zambreno [5], Karthikeyan's one-bit-rotation CORDIC PEs [6], the Kalaycıoğlu two-sided Jacobi design [7], the UCSB scalable engine with Maximum-Data-Sharing ordering [8], and a recent data-stream Jacobi architecture [9]. LU decomposition on systolic arrays traces back to Kung & Leiserson [10] and has similarly wide coverage. On the compiler side, AutoSA [11] pioneered polyhedral-to-systolic compilation on FPGA but does not enforce nearest-neighbor connectivity or AXI4-Stream boundary interfaces [12, 13].

The novelty of this thesis is not another SVD or LU accelerator. It is the compiler-plus-template flow, with LU and SVD serving as demonstrators. LU has been validated end-to-end in the current repository (kung_lu_decom + kung_lu_support); SVD is the new work.

3. Contribution and Thesis Statement

A nearest-neighbor AXI4-Stream PE template, combined with a schedule-generation flow, can emit both a Kung-style LU decomposer and a Brent–Luk–Van Loan two-sided Jacobi SVD engine from a single hardware template, matching or exceeding Vitis HLS on area × latency for both kernels on a Kintex-class target.

Concretely, the thesis will deliver:

  1. A parameterized nearest-neighbor PE template with an AXI4-Stream boundary that respects UG1399 handshake semantics.
  2. A schedule generator that maps LU and BLV Jacobi SVD onto N×N meshes of that template.
  3. Post-place-and-route benchmarks against Vitis HLS on identical C reference and against the closest prior FPGA-SVD numbers.
  4. An open-source release of the flow, sufficient for reproducibility.

4. Approach

4.1 PE template (already prototyped)

The current template exposes N/E/S/W AXI4-Stream ports with TVALID/TREADY/TLAST, a small local register file, and a parameterized arithmetic core. LU uses a divide/subtract/multiply core. SVD will replace this with a two-sided CORDIC rotator so 2×2 Jacobi sweeps can execute in shifts-and-adds.

4.2 SVD case study (new work)

The BLV mesh consists of an n/2 × n/2 array of 2×2 PEs [1]. Diagonal PEs compute rotation angles in vectoring-mode CORDIC and stream them to off-diagonal PEs, which apply them in rotation mode, following the CORDIC-Jacobi pairing established by Hemkumar & Cavallaro [2]. The first milestone is a fixed-point 4×4 SVD matching the baseline shape in Ma et al. [3]. The second milestone is 8×8, which is the largest size widely reported in prior two-sided work and enables a direct comparison.

6. Risks and Mitigations

  • CORDIC accuracy at fixed-point. Mitigation: match the 16-bit fraction starting point used in Ma et al. [3]; only widen if reconstruction error exceeds 1e-3 on 8×8 test matrices.
  • Scope creep into Hestenes / rectangular matrices. Mitigation: keep the thesis to square, two-sided BLV; document Hestenes as future work.
  • Board unavailability. Mitigation: primary target Kintex-7 (already in the lab); simulation-only fallback path exists via the current xsim flow.
  • Vitis HLS producing surprisingly good baselines. This is an acceptable outcome; the paper still stands if the compiler flow matches HLS with a fraction of the DSP count or with strictly nearest-neighbor placement, which HLS does not guarantee.

7. Repository Status (as of proposal date)

  • kung_lu_decom/ — VHDL project, Kung-style LU on the AXI4-Stream PE mesh. Simulation clean.
  • kung_lu_support/ — portable C harness that generates stimulus, extracts L/U, and verifies A = L · U. Runs via make run-sim.
  • kung_svd/ — Vivado project skeleton for SVD experiments; PE core to be replaced with the CORDIC rotator per Section 4.2.
