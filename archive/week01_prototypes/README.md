# Week 01 prototypes (archived)

Early exploratory work exploring a generic AXI4-Stream, nearest-neighbour PE-mesh
template (`mesh_top.sv`, `pe_mac_axis.sv`) driven by a polyhedral loop-schedule mapper
(`mapper.py`). This direction predates and is unrelated to the current VHDL `kung_*`
systolic-array projects (`kung_lu_decom/`, `kung_lu_support/`, `kung_svd/`), which are
the active work.

Kept for reference only — not part of any Vivado/Vitis project and not built or tested
by anything in this repo.
